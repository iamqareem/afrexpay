# Yeezy Theme

A minimalist, warm off-white theme inspired by Yeezy's aesthetic.

## Characteristics
- Warm cream background (#F5F0EB)
- Dark charcoal text (#1A1A1A)
- Earth tone accents (#8A7A6A)
- Clean, editorial product presentation
- Hover reveals add-to-cart button
- No decorative elements (holes, perforations, tags)

## Installation
1. Copy this folder to `/themes/yeezy/`
2. Run `npm run build:css` to generate the CSS
3. Select "yeezy" in the store settings theme picker

## Compatibility
- Works with the `products` vertical only
- Full cart/checkout functionality
- Responsive on all devices
